## 📌 專案背景與封閉開發目標

在國際論文發表、海外留學申請、重要商務談判與高階學術通訊中，高品質的英文書寫是決定成敗的關鍵門檻。
多數寫作者常面臨以下核心困境：
1. **未公開資料的極致隱私保護**：原創草稿、專利數據、未發表論文上傳至第三方雲端有洩漏風險。
2. **格式與低階文法佔用過多 LLM 算力**：科學單位空格缺失（如 `10mL`）、及物動詞錯誤介系詞（如 `discuss about`）、主謂一致性（SVA）、中式雙重連接詞（`although... but`）等，交給 LLM 常引發幻覺或漏改。
3. **缺乏情境適配性**：市面工具多半「一套標準套用所有文體」，無法區分學術期刊論文（嚴謹謙抑）、商務書信（得體外交）、求學自述 SOP（量化成就動詞）與商務決策報告（金字塔結構）。
4. **生硬的搭配詞（Awkward Collocations）**：字詞單看文法正確，但母語人士絕不這樣搭配（例如 *make an experiment*、*statistically big difference*），且一般工具僅提供單一死板改法，缺乏多樣語感選擇。
5. **片面段落被斷章取義**：使用者往往只修改論文其中一節（如僅修 Methodology 或僅修 Introduction），一般 LLM 常誤判「缺乏結論」或「缺少背景」。

**LibreLlama Lab Editor** 於 **v0.9.3 封閉開發版** 引入全新「零 LLM 依賴之學術 NLP 規則管線 (`academic_nlp_pipeline.py`)」與智慧線上更新端點，為即將到來的 **v1.0 正式公開發布** 奠定扎實架構！

---

### 1. ⚡ 零 LLM 依賴之學術 NLP 規則管線 (`academic_nlp_pipeline.py`)
- **雙大功能職責模組**：
  - **Auto-Sanitize（自動無損修正）**：文本送入 LLM 前，以確定性規則直接淨化格式錯誤，顯著降低模型計算負擔。包含：
    - 自動修正科學單位空格（如 `10mL` ➔ `10 mL`, `50uM` ➔ `50 uM`, `37°C` ➔ `37 °C`, `24h` ➔ `24 h`, `12000rpm` ➔ `12000 rpm`）。
    - 自動移除及物動詞後的錯誤介系詞（如 `discuss about` ➔ `discuss`, `mention about` ➔ `mention`, `emphasize on` ➔ `emphasize`）。
  - **Rule-Based Diagnostics（規則診斷報告）**：基於 `spaCy` 依存句法樹（Dependency Parsing）與詞性標註（POS Tagging），回傳結構化 JSON 陣列（`rule_id`, `span`, `matched_text`, `message`, `suggestion`）：
    - 跨子句主謂一致性錯誤（追蹤 `nsubj` 與 `VBZ`/`VBP` / 數一致）。
    - 中式英文雙重連接詞（同一句出現 `although/though... but` 或 `because/since... so`）。
    - 句首裸露指示代名詞（句首 `This/These` 直接作為主詞接動詞，缺乏具體指涉名詞）。
    - 過度名詞化結構（`conduct/perform/make an analysis of` ➔ 建議主動動詞 `analyze`）。
    - 被動語態結構（`auxpass`）與超過 35 字的超長句標記。

### 2. 🌐 100% 保證之雙語審查評語與實證分析 (Bilingual Critiques & Gaps)
- **Reviewer Comment (EN) 必達保證**：後端引入強健中英雙軌容錯合成機制，即使小型模型漏填英文，系統亦自動根據語境合成權威審稿評語，**徹底根除空白框**。
- **實證補強建議 (Strategic & Empirical Gap Analysis)**：嚴格分離正體中文說明與美式英文（US EN）評述，絕無中文文字錯置於英文欄位。

### 3. ⚡ 修改後全文即時規則預檢 (Preflight Rules Linter Diff)
- **免等模型，零延遲快篩**：在啟動深度 LLM 審查前，「修改後全文」區域即時呈現本機規則快篩結果。
- **直觀刪增對照**：以紅色刪除線（`<del>`）標示待改進處，以鮮綠粗體標示推薦替換詞（`[➔ replacement]`），風格與長句提示則以柔和標籤（`[被動語態結構]`）呈現，一目瞭然。

### 4. 🛠️ 整合型底部操作工具列 (Bottom Action Toolbar)
- 將「🚀 開始智能審查」、「⚡ 一鍵自動替換」、進度條與狀態即時指示全數移至視窗底部。
- 一鍵替換無縫串聯 Auto-Sanitize 與口語/縮寫替換，送審文本全自動淨化。

## 📦 使用與啟動方式

1. **直接免安裝執行**：雙擊專案目錄下的 [啟動LibreLlamaLabEditor.bat](file:///c:/Users/Chars%20Hsieh/Desktop/Editor%20project/啟動LibreLlamaLabEditor.bat)。
2. **開發除錯執行**：
   ```powershell
   python LibreLlamaLabEditor.py
   ```
3. **一鍵全自動打包發布（產出單一安裝執行檔）**：
   ```powershell
   python build_release.py
   ```
   *將自動編譯卸載精靈、打包主程式目錄、壓縮套件並產生 `dist/LibreLlamaLabEditor_Setup_v0.9.3.exe`。*
