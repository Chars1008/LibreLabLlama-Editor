## 📌 專案背景與 v1.0.0 公開測試版核心亮點

在國際論文發表、海外留學申請、重要商務談判與高階學術通訊中，高品質的英文書寫是決定成敗的關鍵門檻。
多數寫作者常面臨以下核心困境：
1. **未公開資料的極致隱私保護**：原創草稿、專利數據、未發表論文上傳至第三方雲端有洩漏風險。
2. **格式與低階文法佔用過多 LLM 算力**：科學單位空格缺失（如 `10mL`）、及物動詞錯誤介系詞（如 `discuss about`）、主謂一致性（SVA）、中式雙重連接詞（`although... but`）等，交給 LLM 常引發幻覺或漏改。
3. **長篇捲動與資訊過載疲勞**：傳統審查工具一口氣列出幾十張卡片，垂直捲軸無止盡拖曳，讓使用者難以聚焦當前修訂重點。
4. **搭配詞缺乏直覺互動與語感選擇**：母語人士常用的道地學術動名搭配（如 *substantially mitigates*、*conduct an experiment*）如果只能看死板表格，難以在整篇文章情境中評估效果。

**LibreLlama Lab Editor** 於 **v1.0.0 公開測試版 (Open Beta)** 迎來重磅升級：

### 1. 🗂️ 單卡聚焦輪播檢視 (Single-Card Carousel)
- **擺脫無止境的垂直捲軸**：中間建議欄位全面升級為「一次只呈現一張關鍵建議卡片」，並配備「◀ 上一張」、「下一張 ▶」、首末張跳轉與精準計數器（如 `第 1 / 4 處`）。
- **沉浸式單點聚焦**：讓作者專注於當前修改點的原文對比、審稿評語與風格選項，消除閱讀疲勞。

### 2. 📝 互動式「修改中全文」與懸停浮動搭配詞卡片 (Floating Collocation Cards)
- **中欄新增「修改中全文」互動單元**：即時呈現修訂進度，所有待精進之搭配詞皆以醒目綠色底線高亮。
- **游標懸停 (Hover) 或點擊即刻彈出浮動卡片**：使用者無需在卡片清單中苦苦搜尋，直接將滑鼠移至文字上方即可彈出浮動卡片，自由挑選「頂刊標竿」、「精簡俐落」或「防禦弱化」語感。
- **雙向即時同步連動**：點擊選項後，立即套用至「修改中全文」與「修改後全文」，並自動與單卡輪播的按鈕同步。

### 3. 🛑 隨時中斷推論之「終止審查」按鈕與 60 字元退化迴圈熔斷器
- **推論自主權**：點擊「開始智能審查」後，按鈕立即轉為醒目的紅色「`🛑 終止審查 (Stop Review)`」，隨時點擊即可秒級中止 worker，杜絕介面鎖死。
- **退化重複模式熔斷**：擴展長達 60 字元的退化重複片語（Degenerate Repetition Loop）即時偵測正則，當模型陷入循環時自動截斷並救援 JSON 結構。

### 4. 破除模型惰性與主詞對齊修復
- **解除人為數量約束**：移除 System Prompt 內人為「3 至 6 處」之數量下限枷鎖，導入地毯式逐句檢驗機制，確保所有語病與生硬搭配全數被捕捉。
- **嚴禁省略號與句子對齊**：嚴格禁止大模型輸出 `...` 省略號截斷句子，並導入邊界對齊演算法，杜絕修訂全文主詞重複問題。

## 📦 使用與啟動方式

1. **直接免安裝執行**：雙擊專案目錄下的 [啟動LibreLlamaLabEditor.bat](file:///c:/Users/Chars%20Hsieh/Desktop/Editor%20project/啟動LibreLlamaLabEditor.bat)。
2. **開發除錯執行**：
   ```powershell
   python LibreLlamaLabEditor.py
   ```
3. **一鍵全自動打包發布（產出單一安裝執行檔）**：
   ```powershell
   python build_release.py
   ```
   *將自動編譯卸載精靈、打包主程式目錄、壓縮套件並產生 `dist/LibreLlamaLabEditor_Setup_v1.0.0.exe`。*
